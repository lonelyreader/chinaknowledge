# ADR-0011：宋式编辑部设计方向（从出版物到桥梁）

## Context

网站上线后的核心批评：整体像一份「专业媒体」，而不是通往真实中国人的桥梁；同时「暖米底 + 衬线大标 + 陶土红」组合与当前 AI 生成设计的第一大俗套重合，产品负责人明确表示审美疲劳。深入研究（生产站四页截图审计、六站排版 CSS/浏览器实测、人物与社群呈现十案例对标）确认：问题不在字体与纸色血统，而在参数无人格、结构无签名、人物无兑现；但配色语境必须离开「Claude 系」才能解除第一印象层面的 AI 感。本站命题（真实的人、可核查的事实）恰好提供了一个 AI 模板给不出的方向：水墨丹青、魏晋唐宋的古典容器，装载当代纪实内容。

## Decision

- 设计方向从「克制的编辑出版物」校准为「通往真实的人的桥梁与路由器」：每一屏都应能回答「这背后是谁、如何找到他」；Discord 以三种证据化形态出现（首页社群实况、文末编辑私语式深链、Person 页本人联系渠道）；Person 页升级为成员正式名片。
- 视觉体系确立为**宋式编辑部**：色彩从画论来、版式从册页来、签名从金石来。目标质感为《汉声》、宋人册页、中华书局；明确禁止龙凤纹、祥云、灯笼、鎏金、故宫红黄配、书法字库大标题等仿古景区元素。
- 色板：画布纸灰 `#EFF0EA`（汝窑灰，替代暖米 `#F4F0E7`）、阅读面纸白 `#FBFBF8`；文字灰阶以墨分五色定名定值（焦 `#1A1A16`、浓 `#333330`、重 `#55564F`、淡 `#8A8A80`、清 `#C6C7BE` 为唯一分隔线色）；印泥朱砂 `#A63A2B` 仅以印章尺寸与逻辑出现（署名印、文末印、fact 标记、焦点态），永不作大面积背景；石青 `#2F5D8A` 承担数据、图表与社群制度层；链接为墨下划线。
- 字阶收敛为六级制度：display-xl `clamp(48px,7vw,80px)/1.0`、display-l `clamp(36px,4.5vw,56px)/1.05`、heading-l `clamp(24px,2.5vw,32px)/1.15`、heading-m `20px/1.3`、body `18px/1.65`（移动 `16px`）、meta `12px` mono 全大写字距 `0.08em`。Geist Mono 升格为全站系统层（kicker、日期、图注、按钮、标签、语言切换），作为「当代实录」层制衡古典容器。
- 署名制度为全站唯一签名元素并采用印章体系：文首署名印 + mono 拼音姓名 + 汉字 + 城市 + 编辑判词行；文末「文」字印；竖排汉字栏目侧签；People 索引采用判词名录。汉字层使用思源宋体。
- 摄影为主、水墨只做容器：模板强制图位，纪实摄影优先；水墨质感仅用于封面兜底与 OG 底纹，且必须是受控图片资产，不用 CSS 渐变。标题复读红块生成逻辑废除。
- 留白升格为 spacing 制度（区块间距上调一档）；不对称构图延续现有网格并获得画论依据（马远一角）；正文 measure 收窄至 `620px`（约 65ch）。

## Boundaries

- 字标为固定 artwork（墨 + 朱砂点缀），在纸灰画布上成立，不重制、不重排。
- 不做头像墙、不弹窗、不加社群推广 banner 的既有边界全部保留。
- 紫色、霓虹蓝、金属金、国旗配色、装饰性渐变的禁令保留；石青为制度层功能色，不属于霓虹蓝禁区。
- 本决定只改文档合同；任何页面实现由各自 active 的子级 ChangeContract 授权，色值以真实页面调校结果为最终定值（调校幅度限于同色相微调，方向性变更需回到本 ADR 修订）。

## Consequences

- 后续公开面子级（ARTICLE-TEMPLATE、OG、PERSON-PAGE、HOME）获得可执行的参数级合同，不再各自发明视觉。
- `INFRA-TOKENS-001` 仍按现行值做零视觉 token 化；宋式色板在后续子级以翻转 token 值方式生效，重构与换装解耦。
- 新增实施负担：受控水墨底纹图片资产制作（归入 `INFRA-OG-001`）、思源宋体子集接入（归入首个使用汉字层的子级）、Person schema 需补充编辑判词、本人引语、汉字名与城市字段（归入 `INFRA-PERSON-PAGE-001`）。
- 决策过程与渲染样张存于 Cursor Canvas `visual-direction-proposal`；完整执行细则见 `docs/roadmap/checklists/design-direction-revision.md`。
